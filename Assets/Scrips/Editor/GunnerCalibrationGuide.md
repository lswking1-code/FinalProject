# Gunner 拼接校准

打开 **Tools > Gunner > 拼接校准**。窗口默认读取 `Assets/Prefabs/Player.prefab` 和
`Assets/Arts/PlayerG/GunnerBodyCalibration.asset`，拖动期间只修改临时草稿。

## 建议顺序

1. 在「上半身」步骤从 Idle 开始，使用默认参考腿部。拖动预览中的上半身，或用像素步进按钮调整；不需要移动的帧也可点击「标记已校准」。
2. 勾选需要共享当前修正的帧，点击「应用当前修正到选定图片」。逐帧检查例外，重复出现的 Sprite 共用数据。
3. 切换上半身片段到 Run、Jump、Leap、瞄准、射击、换武器等，仍使用同一个参考腿部校准。
4. 在「腿部腰位」步骤选择下半身片段。预览固定参考上半身，拖动它使腰部接上当前腿部；记录的是当前腿部的腰位变化，不会移动腿部本身。
5. 在「组合预览」选择实际搭配，如 Run 下半身 + Shoot 上半身。暂停后选择「修改对象」为「上半身修正」或「腿部腰位」，即可拖动上半身或使用像素微调，另一项修正保持不变。支持撤销、重做和保存；播放期间禁止编辑。参考腿部腰位仍固定为零，需要调整该组合时选择上半身修正。同一 Sprite 的其他组合也会使用保存的修正。
6. 点击「保存配置」。进入游戏验证分体/全身切换、跑动射击以及 FirePoint 出弹位置。

## 修改动画周期

在窗口的「动画周期」区域选择「上下半身一起」「仅上半身」或「仅下半身」，填写目标秒数，
或点击 0.8 / 1.2 / 1.6 秒快捷值。Idle 建议先预览 1.2 秒。

- 「预览新周期」自动进入组合播放，只改变窗口内的取样时间；「退出预览」恢复资源原来的节奏。
- 「应用并保存周期」才会修改所选 `.anim`。关键帧、最后一帧的停留时间与动画事件按比例缩放，
  保留图片引用、帧序和循环开关；帧数不同的上下半身也可统一总周期。
- 「保存配置」仍然只保存拼接偏移，不会应用正在预览的周期。
- 周期修改支持一次撤销同时恢复两个片段。撤销或重做后，点击「保存当前动画修改」可写回资源。
- 修改的是动画资源本身，所有引用该片段的位置都会使用新周期；实际游戏播放还受 Animator 状态速度影响。
- 只支持可编辑的独立 Sprite `.anim` 片段，目标周期为 0.05～60 秒。

## 坐标和参考

上半身最终位置 = 原始位置 + 当前上半身修正 + 当前腿部腰位。
修正保存在角色根节点本地空间；像素输入会按对应 Sprite 的 PPU 和显示缩放换算。
改变 Pivot 后需重新检查校准。拼接拖动不改 Pivot、动画片段、腿部或碰撞体；只有明确点击「应用并保存周期」才会修改动画时间。

参考腿部的腰位固定为零。开始校准后锁定两个参考 Sprite，避免整个配置的基准被意外改变。
如需更换参考，使用「清空草稿校准并解锁参考」，该操作可撤销，保存前不影响已有配置。

## 草稿和片段

- 窗口关闭时会提示保存或丢弃未保存修改。重新读取配置会丢弃草稿，并在有修改时确认。
- 「撤销 / 重做」使用 Unity Undo。一次鼠标拖动合并成一次撤销操作。
- 「重置本图」删除该图片的修正，使它重新显示为未校准。零修正也可以明确标记为已校准。
- 支持一条 SpriteRenderer Sprite 轨道的片段；额外数值动画轨道会提示不支持，避免预览与运行时不一致。
- 播放按关键帧时间取样。循环片段循环播放，非循环片段停在结尾；组合预览中循环轨道按各自时长循环。
- 非循环片段的上一帧/下一帧在首尾保持，不会绕回另一端。组合逐帧仅在两个片段都循环时绕回；Jump 上下半身均为非循环，结束时保持各自末帧。
- 同一张 Sprite 在不同片段中共享修正。首版不支持对同一张图片按状态保存不同的修正。

## 验证

**Tools > Gunner > 验证拼接校准逻辑** 在临时对象上运行坐标、切换、Undo、采样和保存重载检查。
不会启动游戏或修改用户场景；保存重载检查会创建并删除一个具有唯一名称的临时校准资源。

**Tools > Gunner > 验证拼接窗口交互** 会打开一个独立测试窗口，模拟拖动、翻转、撤销、重做与保存，
然后关闭窗口并清理临时资源。已有校准草稿和正式配置不会被覆盖。

**Tools > Gunner > 验证动画周期修改** 使用 Idle 的临时副本检查周期预览、双片段修改、关键帧和事件、
撤销重做、保存重载及非法输入，不修改正式 Idle 资源。

## 枪口标记

1. 选择射击用的上下半身片段，切到「组合预览」并暂停。
2. 勾选「编辑枪口标记」，选择实际武器和射击方向。
3. 点击画面中的枪口，或拖动十字标记；也可输入原图像素坐标、按 1px 微调。橙色表示尚未设置，绿色表示已有标记。
4. 逐帧检查。勾选上半身图片后可批量应用相同的原图像素坐标；不同构图请分别设置。
5. 点击「保存配置」。拖动期间只改草稿，一次拖动支持一次撤销；「删除本图枪口」恢复原 FirePoint。

标记按 Sprite 引用、武器 ID、射击方向保存，以原图左下角为零。相同图片在其他动画中共享标记。
运行时转换 Sprite Pivot、PPU、Renderer 翻转及角色 Transform，跟随校准后的上半身与腿部腰位。
更换身体校准参考不删除枪口标记。普通出弹及持续激光在 Animator 更新后读取枪口，避免读取上一帧图片。
未标记图片、空图片及蹲姿等全身动作仍使用原 FirePoint；本版窗口仅编辑分体枪口。
配置中不会预填猜测的位置。请在游戏内验收跑动射击、上下射击、左右翻转和持续激光。
