# 机械师击中特效

已自动接入现有机械师攻击，不需要给场景或预制体重新挂组件。

## 表现

- 普通弹、S 特殊弹：白色亮芯与橙黄像素火花。
- 射击连招终结弹、蓄力弹、L 特殊弹、标记炸弹：较大的命中闪光与扩散环。
- M 特殊弹、机器人贯穿激光：蓝白电火花。
- 机械师近战、机器人近战：命中亮闪叠加短促斩击；Blast 近战更大。
- 盾牌吸收、抵销敌方飞行道具：冷白金属火花。
- 子弹撞地形或推动场景物件：较小的冷色碰撞火花。

特效约持续 0.19–0.27 秒，按 26 fps 播放，使用 Point 采样保持像素边缘。每次在独立世界位置播放，不跟随已销毁的子弹。特效处于 Bullet 排序层、Order 20/21；使用不受场景光照影响的专用材质。

## 调整

在 Project 面板选择 `Assets/Resources/MachinistImpactLibrary.asset`：

- `Size`：全局尺寸，默认 1。
- `Frames Per Second`：播放速度，默认 26。
- `Warm / Energy / Metal`：普通、能量、金属色。
- `Sorting Layer / Sorting Order`：绘制层级。
- `Pool Capacity`：同时存在的特效上限，默认 48。

每个 `Attack` 的“机械师命中特效”栏目可设置 `Impact Kind` 与 `Impact Scale`。默认 Auto 只识别机械师专用弹药、机械师和机器人子物体下的近战、标记炸弹；None 可单独关闭。其他角色和敌人的攻击默认不受影响。

受伤成功、盾牌实际吸收、可击打机关接受命中或撞墙后才播放相应特效。无敌拒绝伤害时不播放成功命中效果。复合碰撞体按 Character 去重；连续特效最短间隔 75 ms；投射物一次消耗只显示一次。去重只作用于特效，不修改原本的伤害、无敌、弹药、击退、命中节奏或动画事件。

## 资源与参考

本目录 PNG 是项目内现有 Warped shooting fx 的 hits 1/2/3 以及 `VFX/vSlash1.png` 的原样副本，没有下载替换美术。副本使用完整帧画布和独立导入设置，避免旧自动裁切造成播放时跳动。斩击原条带按四个 64×48 帧切分。专用 Shader 将原蓝色边缘映射到对应攻击颜色，并保留高亮中心。

风格参考入口：[SNK《合金弹头》官方展示](https://www.snk-corp.co.jp/us/games/metalslug_attack_re/)、[Tribute Games《Mercenary Kings》动画展示](https://blog.tributegames.com/post/82109499915/mercenary-kings-animations)。这里采用像素轮廓、明亮接触点和短时间消散的设计方向；具体尺寸、帧率及配色是本项目的调校值。

## 验证建议

在实际关卡尝试普通射击、四连射、各类蓄力与特殊弹、完整近战连招、盾兵正面/背面、上下方向射击和机器人贯穿激光。特效已经接入这些路径；不同关卡的背景、遮挡与目标密度仍可按实际游玩偏好继续调节。
