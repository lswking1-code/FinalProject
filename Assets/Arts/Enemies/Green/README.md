# 四类士兵绿色版本

根据用户提供的绿色迷彩参考图配色，沿用 enemy_default.png 到 enemy_default_p.png 的胸腹护甲、靴子换色部位。使用深军绿、军绿、橄榄绿和浅橄榄绿四级色阶：#1D2A19、#3C5331、#708141、#979E52。

用户已明确授权程序精确换色。本次没有重新绘制，没有使用图像生成提示词。具有紫色对应图的动画使用紫色服装部位作为蒙版；其余动画根据原服装色阶识别，红色和紫色变体统一映射至绿色。保留原尺寸、逐像素透明度以及换色区域以外的像素。

23张绿色PNG包含四类士兵的角色图及待机、移动、攻击、受击、死亡等动画图集。对应.meta沿用原切片、轴心、PPU和导入参数，资源GUID独立。Manifest.json记录每张来源、改变像素数、原文件校验值及资源对应关系。

Animations目录包含四类士兵当前控制器及其引用动画的独立绿色副本，仅更换资源引用；帧时间、动画事件、伤害相关曲线和状态机均保留。原始图集、动画、控制器和场景中的现有士兵不替换。

Green_Comparison.png为静态对照，每组左侧原版、右侧绿色版。

验证：所有输出与来源尺寸及alpha逐像素一致；蒙版以外像素一致；原PNG与meta校验值未变；复制的动画和控制器在还原GUID后与来源内容完全一致。已检查代表性整套帧图；未运行Unity场景测试。
