# Stage1 / Stage2 机关美术

使用 Stage2 现有工业门的深灰钢板、金属铆钉、黄黑警示条与暖色铜件。所有状态图统一为 **32×32 方形、Point 采样、无压缩、无 Mipmap、透明 PNG**。按后续尺寸调整要求，导入 PPU 从 32 改为 32÷1.5（约 21.333334），方形图的显示尺寸统一为 **1.5×1.5 世界单位**。

- `EnergyNode_*`：32×32。闪电接收口和感应线圈；未充能、满电、半电、低电量四种状态。锁定充能时保持满电图。
- `TimedChargeNode_*`：32×32。时钟和剩余时间灯；未激活、开始计时、时间过半、即将结束四种状态。
- `DestructionNode_*`：32×32。靶心和门锁；完整、首次损伤、累计命中达到一半、摧毁四种状态。
- `ToggleSwitch_*`：32×32。统一方形钢板外壳，左拨杆／圆形灯表示关，右拨杆／竖条灯表示开。

四张原始设计使用内置 image_gen 生成，提示词保存在 `GenerationPrompts.json`。交付图片经过色键去底、最近邻缩小和限色整理，具有真实透明通道。

`MechanismVisual` 仅读取现有机关公开状态，选择对应的 Sprite，不处理攻击、碰撞、计时或开门事件。充能剩余量 ≤50% 显示半电，≤25% 显示低电；未激活回到待机。摧毁图的显示时长沿用现有节点销毁逻辑。原有受击闪色继续作用于新图。

美术挂在机关的 `MechanismArt` 子节点。子节点保持单位世界缩放，抵消父级缩放；通过 Sprite 的 PPU 放大显示，不改变碰撞体。开关图中心上移 0.25 单位，与原碰撞盒中心一致。旧占位图只关闭显示，保留原组件与接线。

接入范围：Stage1 的 3 个摧毁核心；Stage2 的 7 个 EnergyNode、2 个 TimedChargeNode、3 个 ToggleSwitch、3 个摧毁核心。保留现有门体及 OverheadDoor 的受击执行器。

Unity 菜单 `Lost Division > Art > Apply Stage1 and Stage2 Mechanism Art` 可再次应用。工具会检查两关是否存在未保存编辑，并保留其他已打开场景。
